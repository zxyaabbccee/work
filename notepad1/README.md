# 记事本应用 (NotePad)

这是我在Android开发课程中做的一个小项目，一个简单但实用的记事本应用。主要用来记录日常的一些想法、待办事项，还可以给笔记分类，方便查找。

## 项目结构

简单说一下项目的文件组织情况：
```
NotePad/
 ├── app/
 │   ├── src/main/java/com/example/notepad/ # 主要的Java代码
 │   ├── src/main/res/                      # 资源文件（布局、样式、图标等）
 │   └── AndroidManifest.xml                # 应用配置文件
 ├── screenshots/                           # 应用截图
 └── README.md                              # 就是现在看的这个说明文件
```

## 功能介绍

### 基本功能
- 创建、编辑和删除笔记
- 查看所有笔记列表
- 给笔记添加标题和内容

### 进阶功能
- **分类管理**：可以给笔记分不同类别（工作、学习、生活等），不同类别有不同颜色的标签
- **搜索功能**：在顶部的搜索框输入关键词就能找到相关笔记
- **时间显示**：会显示相对时间，比如"刚刚"、"5分钟前"、"昨天"等
- **代办标记**：可以把笔记标记为待办事项，并设置截止时间
- **导出分享**：支持把笔记导出或者分享给其他应用

## 用了哪些技术

- 开发语言：Java
- 开发环境：Android Studio
- 数据存储：SQLite数据库
- 界面组件：用了RecyclerView来显示列表，还有一些基本的Android控件
- 兼容性：支持Android 5.0及以上版本

## 怎么运行这个项目

1. 先确保电脑上装了Android Studio
2. 克隆或者下载这个项目到本地
3. 在Android Studio中打开项目文件夹
4. 等待Gradle同步完成（可能需要一点时间）
5. 连接手机或者启动模拟器
6. 点击运行按钮就可以了

## 使用说明

### 创建笔记
- 点击右上角的"+"号按钮
- 输入标题和内容
- 选择一个分类（可以用默认分类）
- 点保存按钮就完成了

### 编辑笔记
- 在列表中点击要改的笔记
- 修改内容后点保存

### 删除笔记
- 在编辑页面点右上角的删除按钮
- 确认一下就删掉了

### 搜索笔记
- 在首页顶部的搜索框输入关键词
- 列表会自动显示包含关键词的笔记

### 分类管理
- 创建或编辑笔记时可以选择分类
- 首页菜单里有分类筛选功能，可以只看某一类的笔记
